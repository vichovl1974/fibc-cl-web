Glosario

Glosario técnico

Términos básicos para entender Big Bags, FIBC, sacos PP y Código UN.

FIBC

Flexible Intermediate Bulk Container. Envase flexible de gran capacidad, conocido como Big Bag.

SWL

Safe Working Load. Carga máxima de trabajo segura.

Liner

Bolsa interior usada para proteger el producto o evitar pérdida de polvo.

Coating / Laminado

Revestimiento de la tela para reducir paso de humedad o polvo.

Número ONU

Identifica la mercancía peligrosa. Ejemplo: UN 1823.

Marcado UN

Identifica el envase aprobado o certificado. No es lo mismo que el número ONU del producto.

IMDG Code

Código marítimo internacional de mercancías peligrosas.

SOLAS

Convenio internacional para la seguridad de la vida humana en el mar.

Orange Book

Recomendaciones de Naciones Unidas sobre transporte de mercancías peligrosas, base de la reglamentación modelo.
